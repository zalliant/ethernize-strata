# zalliant/ethernize-strata

Strata: database access (PDO), query builder and migrations.

This repository is a **read-only split** of the Zalliant Ethernize monorepo. Report issues and
send changes to the monorepo; this repository is regenerated from it.

**Experimental.** Version 0.1.0-beta.1: the API can change between betas.

```bash
composer require zalliant/ethernize-strata:^0.1.0-beta.1
```
